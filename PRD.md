Product Requirements Document: Backend v2.0 (Migration & AI)Date: December 16, 2025Status: DraftPriority: Critical (January Launch)1. Executive SummaryThis update focuses on a critical infrastructure pivot of the backend services from Render/AWS to Google Cloud Platform (GCP) to leverage ecosystem credits and native AI capabilities. Functionally, the backend must support a new B2B Enterprise Licensing model for schools, a lightweight Content Management System (CMS) for blogs, and a direct integration with the Google Gemini API.2. Infrastructure Migration (Critical)2.1 Cloud Provider PivotCurrent State: Backend hosted on Render (or AWS attempts).Target: Migrate Backend services to Google Cloud Platform (GCP).Frontend Strategy: Frontend remains on Netlify (Hybrid Architecture).Action Items:Containerize the Node.js application (Docker) for deployment on Google Cloud Run (serverless, scalable).Migrate Redis (if self-hosted) to Google Cloud Memorystore or a managed Redis instance on GCP.Configure CORS in src/app.ts to explicitly allow requests from the Netlify frontend domain.Apply for the $300 Google Cloud startup credits immediately.3. Core Functional Requirements3.1 AI Integration (Gemini API)Goal: "Inculcate AI features" to assist students.Implementation:New Service: src/services/geminiService.ts.Library: Install @google/generative-ai.Endpoint: POST /api/v1/ai/tutorInput: { "context": "Lesson content...", "question": "Student question..." }Output: AI explanation text.Security: API Key must be stored in GCP Secret Manager, not .env files in repo.3.2 B2B / Enterprise Licensing SystemGoal: Enable bulk sales to schools (batches of 100, 200, 500, 1000).New Data Model: LicenseBatch (Schema)schoolName (String)licenseKey (String, Unique) - The code students use to sign up.maxUsers (Number) - e.g., 500.enrolledCount (Number) - Tracks usage.expiryDate (Date)isActive (Boolean)Auth Controller Updates:Modify register logic to accept an optional licenseKey.If licenseKey is provided:Validate key existence and isActive.Check if enrolledCount < maxUsers.Increment enrolledCount.Assign user role student and tag them with organizationId.Bypass payment requirement.3.3 Blog & "Nurtured" Content SystemGoal: Support marketing content.New Data Model: BlogPost (Schema)title (String)slug (String, Unique)content (String/Markdown)type (Enum: 'BLOG', 'NURTURED') - Distinguishes between standard blog and "Nurtured" pages.published (Boolean)Endpoints:GET /api/v1/content/posts (Public, filtered by type)GET /api/v1/content/posts/:slug (Public)POST /api/v1/admin/content (Admin only)3.4 Scope Reduction (Geography)Goal: Stabilize the platform by removing problematic modules.Action:Modify src/config/curriculum.ts or src/controllers/oakContentController.ts to filter out "Geography" from the fetched subject lists before sending the response to the frontend.Do not delete the logic, but implement a "Blocklist" array: const BLOCKED_SUBJECTS = ['geography'];4.
